# Fonts — usable casting guide

> **Truth box:** Her actual font files were NOT confirmed in any post, caption, comment, or Substack page. Everything below is a *casting match* — free fonts close in character, chosen so you can build in this system today. If you need her exact fonts, the only source is her.

## Install in 2 minutes
- **Google Fonts (free):** Anton · Oswald (300/500/700) · Pirata One · Playfair Display · EB Garamond · Nunito (700/800) · Courier Prime — all in `02-fonts.css`, import it or download from fonts.google.com
- **Canva:** Anton, Oswald, Playfair Display, EB Garamond, Nunito and Courier Prime are all searchable in Canva's font picker. Pirata One may need uploading as a brand font (Pro).
- **Adobe Fonts alternatives:** Oswald ≈ Franklin Gothic Condensed vibes; Playfair ≈ Kepler / Freight Display vibes; Courier Prime ≈ Courier / Letter Gothic vibes. (Character matches, not claims.)

## Type rules that actually make it look like her
1. Title is 3–4× the director size. If the hierarchy feels polite, it's wrong.
2. Hairline credit is always present, always at the top, always absurdly small and wide-tracked.
3. Never set a synopsis in the display face. The contrast condensed/brand-bold vs. literary italic IS the signature.
4. Centre everything in list posts. Left-align ONLY in FrameXFrame/typewriter essays.
5. Accessibility fix she gets criticised for: don't go below 27 units for synopsis on a 1080 canvas. Her small type is the look — and the complaint.
