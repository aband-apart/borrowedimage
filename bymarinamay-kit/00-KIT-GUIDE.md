**What this is:** A working production kit built from the full brand audit (Oct 24, 2026) — palette files you can import, font casting you can install today, 8 editable carousel templates, caption templates, a sticker/frame library, and a production checklist. Open this file first; everything else in the folder plugs into it.

**What this is not:** Her source files. Her actual fonts were never confirmed in any visible source, and her hex values are screenshot estimates. This kit recreates the *system* faithfully with free, licensed-for-use tools. Credit/audit trail is in the companion audit document (`bymarinamay-brand-audit-2026-10-24.md`, not included in this folder).

## The system on one page

**Canvas:** 1080 × 1350 (4:5) for every carousel slide. Reels covers: 1080 × 1920, using the same flat colour + big type + mark.

**Fixed skeleton (every post, no exceptions):**
1. Flat grainy ground — ONE colour, topic-coded (table below)
2. Hairline credit, top centre, tiny spaced caps
3. Huge display title — topic-cast face
4. One central image in the series frame — halftone/duotone/sepia, cut out
5. Director, small, always
6. Synopsis/body, small — italic serif (lists), typewriter (essays), rounded sans (text-forward)
7. Heart-arrow sign-off mark, tiny, foot centre *(the templates include a simplified original drawing in that position — replace it with your own mark, and fill the `[YOUR HANDLE]` slot in the hairline credits, if this kit is for your own account)*
8. End card — ONE CTA only

## Build a carousel in 20 minutes (workflow)

1. **Pick the row** above. Lock ground, face, frame before you touch content.
2. **Duplicate the matching SVG template** per film (01 cover, then the series slide × N, then 08 or a follow end card).
3. **Drop in stills.** Halftone/duotone them with the recipes in file 04. Full colour only for art-analysis posts.
4. **Set type in this order:** title → director → cast/status → synopsis (2 lines max — if it needs 3, cut words, don't shrink type below the floor in file 02).
5. **Stickers (Upcoming only):** 3–5, from file 04, overlapping edges, slight rotations, one sticker system per post.
6. **Grain last.** Overlay the grain PNG (or your tool's noise step) over the flattened slide.
7. **Caption** from file 03, matching template. Personal → database → question. 5–6 hashtags.
8. **Run the checklist** below before scheduling. Her observed rhythm: ~9:00 a.m., near-daily in season — consistency is part of the brand, batching is how a solo creator survives it.

## Production checklist
- [ ] One ground colour, and it's the *right topic's* colour
- [ ] Hairline credit present and tiny; logo present and tiny — neither competes with the title
- [ ] Title is 3–4× director size; director is on EVERY film slide
- [ ] Every photo halftoned/duotoned/sepia — except art-analysis stills
- [ ] Grain applied to the final export, not the working layers
- [ ] Synopsis ≤2 lines at size floor; no orphan sticker covering a face or title letter
- [ ] Cover works as a thumbnail: could you name the series at grid size, without reading it?
- [ ] End card has exactly one CTA (Substack for essays; follow + Letterboxd for lists)
- [ ] Caption: lowercase, personal first, omissions pre-empted, one question, 5–6 hashtags
- [ ] Real vs. speculative titles are labelled with status in the caption (her audience asks — answer before they do)
- [ ] Export: PNG, sRGB, 1080×1350, slides in story order, alt text per slide if your tool supports it

## Substack companion settings (from the audit)
Page ground/header band: pale blue-grey #DCE6EA · Headline: elegant serif, dark teal-grey, title case · Subtitle: italic serif, grey · Body: clean sans, dark slate · Drop cap: large, brown · Divider: the heart-arrow mark in red, small · Section label (FrameXFrame): small sans caps. No stickers, no duotone — Substack is the quiet register of the same brand.
